# Brag Plan: SkinAge Atlas

## What is this app?
SkinAge Atlas is an end-to-end, leak-free, reproducible computational biology platform that analyzes chronological ageing and UV photoaging across human skin cohorts and tests whether in vitro machine learning age clocks generalise to in vivo clinical tissue.

## The angle
High-tech translational bioinformatics meets uncompromising statistical rigor. We didn't hide cross-platform failures—we demonstrated why fibroblast clocks dilute in full-thickness skin, delivering an interactive Streamlit & Plotly platform backed by verified NCBI GEO datasets.

## Hook (first 2-3 seconds)
Big bold typography on dark aesthetic: "Can an AI predict human skin age from RNA-seq?" followed by a swift zoom into the transcriptomic volcano plot.

## Key moments (the middle)
- **Beat 1 (Discovery & Rigor):** 82 human donors (ages 22–89), 20,798 genes, continuous age regression with sex adjustment.
- **Beat 2 (Pathway Shifts):** GSEA reveal showing senescence secretome activation (`Protein Secretion` NES = +2.37) and lipid barrier decline (`Cholesterol Homeostasis` NES = -1.69).
- **Beat 3 (The Machine Learning Clock):** Elastic Net 5-fold cross-validation with Pearson r = 0.706, MAE = 10.67 years, alongside the radial age gauge simulator.
- **Beat 4 (Independent Transfer Reality):** Honest cross-platform evaluation on whole-skin microarrays (MAE = 48.85y) and the translational deconvolution roadmap.

## Outro / punchline
"12 publication figures. Zero data leakage. Fully reproducible." Ending with GitHub repository link: `github.com/ypadhi27/SkinAge-Atlas`.

## User flow worth showing
1. Exploration: 2D & 3D PCA dimensional reduction colored by chronological age.
2. Dynamic Analysis: Interactive volcano sliders filtering significant aging biomarkers in real-time.
3. Prediction: Live transcriptomic age gauge comparing actual vs predicted donor age.
